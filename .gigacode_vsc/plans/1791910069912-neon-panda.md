# План: Подготовка README для демонстрации на собеседовании

## Проблема

Модель `my-api-docs:latest` (Mistral 7B Instruct v0.3 + LoRA адаптер) хранится локально. README не описывает, как подготовить модель для демонстрации. Есть несоответствия в настройках (embedding model, VECTOR_SIZE).

## Решение

**Обновить README.md с разделом "Подготовка к демонстрации" + исправить несоответствия.**

## Шаги

### 1. Обновить README.md — добавить раздел "Подготовка к демонстрации"

**Добавить после раздела "Установка зависимостей":**

```markdown
### 3.5 Подготовка дообученной модели (для демонстрации)

Проект использует дообученную модель **Mistral 7B Instruct v0.3** с LoRA адаптером для генерации API-документации.

**Модель уже установлена локально.** Для демонстрации на собеседовании:

1. Убедитесь, что Ollama запущен: `ollama serve`
2. Проверьте установку моделей:
   ```bash
   ollama list
   ```
   Должны быть:
   - `my-api-docs:latest` — дообученная модель (Mistral 7B + LoRA)
   - `mxbai-embed-large:latest` — модель для эмбеддингов

**Если модель не установлена:**
```bash
# Базовая модель Mistral 7B Instruct v0.3 (q4 quantization)
ollama pull mistral-7b-instruct-v0.3-q4_k_m

# LoRA адаптер (загрузить с HuggingFace)
# Репозиторий: https://huggingface.co/NikSokol99/mistral-api-docs-tuned

# Собрать модель
ollama create my-api-docs -f Modelfile

# Модель для эмбеддингов
ollama pull mxbai-embed-large
```

**Требования к GPU:**
- Минимум: 4 ГБ VRAM (q4 quantization)
- Рекомендуется: 8 ГБ VRAM
```

### 4. Добавить Modelfile в репозиторий

**Файл `Modelfile` в корне проекта:**
```
FROM https://huggingface.co/TheBloke/mistral-7b-instruct-v0.3-GGUF/resolve/main/mistral-7b-instruct-v0.3.Q4_K_M.gguf
ADAPTER D:\OllamaModels\blobs\sha256-72b77c6dd6da8c809058e8b1513cd0e4c43c0ac808679efabcf2e33a91ede4a2
TEMPLATE """[INST] {{ range $index, $_ := .Messages }}
{{- if eq .Role "system" }}{{ .Content }}

{{ else if eq .Role "user" }}{{ .Content }}[/INST]
{{- else if eq .Role "assistant" }} {{ .Content }}</s>[INST] {{ end }}
{{- end }}"""
PARAMETER stop  [INST]
PARAMETER stop  [/INST]
PARAMETER stop  </s>
```

> **Примечание:** ADAPTER указывает на локальный файл. Для публикации на GitHub заменить на URL с HuggingFace.

### 5. Добавить скрипт для проверки модели

**Файл `scripts/check_model.bat` (для Windows):**

```batch
@echo off
echo ====================================
echo AI Docs Assistant - Проверка модели
echo ====================================

echo.
echo Проверка Ollama...
ollama list >nul 2>&1
if %errorlevel% equ 0 (
    echo ✓ Ollama запущен
) else (
    echo ✗ Ollama не запущен. Запустите: ollama serve
    exit /b 1
)

echo.
echo Проверка модели my-api-docs...
ollama list | findstr "my-api-docs" >nul
if %errorlevel% equ 0 (
    echo ✓ Модель my-api-docs найдена
) else (
    echo ✗ Модель my-api-docs не найдена
)

echo.
echo Проверка embedding модели...
ollama list | findstr "mxbai-embed-large" >nul
if %errorlevel% equ 0 (
    echo ✓ mxbai-embed-large найдена
) else (
    echo ✗ mxbai-embed-large не найдена
)

echo.
echo ====================================
echo Проверка завершена!
echo ====================================
```
